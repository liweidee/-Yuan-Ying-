  - [x] 双击快进/快退

  - [x] 垂直方向调节亮度/音量

  - [x] 水平方向手势快进/快退

  - [x] 弹幕
  - [x] 字幕
  - [x] 记忆播放
  - [x] 视频比例：高度/宽度适应、填充、包含等

  - [x] 热搜
  - [x] 搜索历史
